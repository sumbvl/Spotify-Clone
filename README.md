# Spotify Clone

A lightweight Spotify web player clone built using **React**, **Vite**, **Tailwind CSS**, and **React Router DOM**.

---

## Features

- **Music Playback**: Play, pause, skip, and loop audio tracks.
- **Dynamic Routing**: View curated playlists and browse individual playlist tracks.
- **Global Audio State**: Audio playback managed globally across pages using React Context API (`PlayerContext`).
- **Responsive Navigation**: Top navigation bar with search bar and Spotify-style UI controls.


## Getting Started

### Prerequisites

Ensure you have **Node.js** (v16 or higher) installed on your machine.

### Installation

1. **Clone the repository:**
```bash
git clone [https://github.com/your-username/spotify-clone.git](https://github.com/your-username/spotify-clone.git)
cd spotify-clone

```


2. **Install dependencies:**
```bash
npm install

```


3. **Start the development server:**
```bash
npm run dev

```


4. **Open in browser:**
Navigate to `http://localhost:5173` (or the URL shown in your terminal).
